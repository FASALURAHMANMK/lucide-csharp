Lucide C# — Codex End-to-End Build Prompts (copy/paste into Codex)
==================================================================

Context
-------
You are building an open-source project named **Lucide C#** (repo: lucide-csharp).
Goal: Provide a first-class Lucide icon library for the C# ecosystem (WPF, WinForms, Blazor), supporting .NET Framework 4.8 through .NET 10, with maximum performance and dev-friendly APIs. Produce NuGet-ready packages, docs, and CI publish workflows.

Rules
-----
- Follow the repo structure and requirements defined in `agent.md`.
- Do not parse SVG on each render; implement caching.
- Core is renderer-agnostic. SharpVectors is only for WPF rendering.
- Icons are stored as one embedded binary blob + generated offset table.
- Provide documentation and publishing workflows.
- Commit in logical steps. After each major step, ensure `dotnet build` passes.

PROMPT 2 — Implement versioning system
--------------------------------------

   - Use MSBuild props import (e.g., generate a `Version.props` during build via script) OR simpler:
     - keep a `Directory.Version.props` generated by script and committed.

Acceptance:

PROMPT 3 — Implement generator tool (eng/icons/generator)
---------------------------------------------------------
1) Create a .NET console tool `Lucide.Generator` that takes:
   - `--input <folder>` where lucide SVG files exist (canonical upstream layout)
   - `--output <repo_root>`
   - `--compress gzip`
2) The generator must:
   - Load all `*.svg`
   - Normalize icon names to PascalCase for enum (`shopping-cart` => `ShoppingCart`)
   - Generate:
     - src/Lucide.NET.Core/Generated/LucideIconKind.g.cs
     - src/Lucide.NET.Core/Generated/LucideAliases.g.cs (dictionary: string -> LucideIconKind)
     - src/Lucide.NET.Core/Generated/LucideIconIndex.g.cs (offset/length table)
     - src/Lucide.NET.Core/Resources/lucide_icons.bin (embedded resource)
3) Binary format:
   - concatenated gzip bytes for each SVG
   - index table stores offset and length for each kind, plus a constant compression enum
4) Validate:
   - no duplicate normalized names
   - emit a `generator-report.json` with counts and list of icons

Add scripts:
- eng/icons/update-lucide.ps1: downloads lucide SVGs OR (simpler) expects user to provide local path; include both modes.
- eng/icons/generate.ps1: runs generator and ensures generated files exist.

Acceptance:
- Running generator on a sample input folder generates all files.
- `Lucide.NET.Core` compiles using generated code.

PROMPT 4 — Implement Lucide.NET.Core
------------------------------------
1) Add interfaces and classes:
   - ILucideIconSource (GetSvg(kind))
   - EmbeddedLucideIconSource reads bin + index table and returns decompressed SVG string (cached)
   - LucideOptions:
     - StrokeWidth (float, default 2)
     - UseCurrentColor (bool, default true)
     - LineCap (Round/Butt/Square)
     - LineJoin (Round/Miter/Bevel)
     - Optional: IncludeXmlns (bool default true)
2) Implement static facade:
   - class `Lucide` with:
     - `string GetSvg(LucideIconKind kind, LucideOptions? options = null)`
     - `bool TryResolve(string name, out LucideIconKind kind)`
     - `IReadOnlyList<string> GetAllNames()` optional
3) Apply styling:
   - Lucide SVG uses `stroke="currentColor"` and `stroke-width="2"` by default.
   - Implement option substitution by updating attributes in the root `<svg ...>` tag:
     - stroke-width
     - stroke-linecap
     - stroke-linejoin
     - stroke (currentColor or a provided color string if you include it)
   - Keep it simple and fast: minimal string operations, no XML DOM.

Acceptance:
- `Lucide.GetSvg(Home)` returns valid SVG markup.
- `TryResolve("shopping-cart")` and `TryResolve("ShoppingCart")` succeed.

PROMPT 5 — Implement Lucide.NET.Wpf

   - DependencyProperties:
     - Kind (LucideIconKind)
     - Stroke (Brush)
     - StrokeThickness (double)
     - Size (double) or Width/Height binding friendly (prefer Width/Height)

3) Implement caching:
   - Cache `DrawingImage` by key:

4) Provide MarkupExtension `LucideImageExtension`:
   - Usage: `{lucide:LucideImage Home, Size=18, Brush={StaticResource ...}}`
5) Add WPF sample app demonstrating a grid of icons and theming with MaterialDesign or plain WPF.

Acceptance:
- WpfDemo shows icons quickly.
- Rendering does not re-parse SVG on every control load (validate by logging or tests).
